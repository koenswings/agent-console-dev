# Icons

Line icons copied from [Tabler Icons](https://tabler.io/icons) v3.53.0 (outline set), MIT licence (see `LICENSE` in this folder).

Only the SVG paths the Console uses are kept, in `tabler.tsx`, so they are bundled with the app and work offline. To add one, copy the `d` values of its `<path>` elements (skip the `stroke="none"` bounding-box path) from `icons/outline/<name>.svg` in the `@tabler/icons` package.

| Name | Used for |
|---|---|
| `plug-connected` | Top bar: Connections |
| `user` | Top bar: Account |
| `history` | Top bar: History; mobile tab bar: History |
| `settings` | Top bar: Settings |
| `x` | Top bar: close the open panel |
| `package` | Mobile tab bar: Apps |
| `network` | Mobile tab bar: Network |
| `bolt` | Mobile tab bar: Activity |
| `eye` | Password field: Show password |
| `eye-off` | Password field: Hide password |
